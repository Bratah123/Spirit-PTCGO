# Custom Deck Box Flats

Unfolded (UV-layout) textures for the 3D deck box on the in-game playmat, served as
`deckboxFlats/<name>`.

See the two example pngs already in here for the two different type of deck box shapes.

* **Resolution:** `512x512` PNG (non-standard sizes are scaled).
* **Naming:** lowercase, matching the deck box product's image name (its 2D icon in
  `custom_deckboxes/` uses the same name).
* Boxes without a flat here (or in `deckboxFlats.template`) fall back to the red & white default deck box.
